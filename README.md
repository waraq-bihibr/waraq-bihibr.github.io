# ورق بحبر

منصة رقمية لبيع الكتب الجامعية والمراجع الأكاديمية المستعملة وشرائها وتبادلها والتبرع بها لمكتبة المنصة، مع خدمة توصيل مجدولة منخفضة التكلفة.

مشروع تخرج · مسار المشاريع الرقمية · قسم الإعلام الإلكتروني · الجامعة السعودية الإلكترونية.

**الموقع المنشور:** https://waraq-bihibr.github.io

**نسخة احتياطية على Netlify:** https://waraq-bihibr.netlify.app

---

## محتويات المجلد

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية التي تُفتح في المتصفح |
| `css/style.css` | التصميم: الألوان والخطوط والتخطيط والوضع الليلي والتوافق مع الجوال |
| `js/data.js` | الإعدادات (فترات التوصيل والرسوم والمدن ورابط الاستبيان) والبيانات التجريبية ومحتوى المركز الإعلامي |
| `js/app.js` | منطق المنصة: التنقل بين الصفحات، وتسجيل الدخول، وعرض الكتب، والطلبات، والتبادل، والتبرع |
| `assets/favicon.svg` | أيقونة المتصفح |
| `assets/og-image.png` | صورة المشاركة على منصات التواصل |
| `netlify.toml` | إعداد الاستضافة على Netlify |

بُنيت المنصة بـ HTML وCSS وJavaScript فقط، دون أي مكتبات خارجية.

## التشغيل في Visual Studio Code

1. افتح المجلد في VS Code.
2. ثبّت إضافة **Live Server**، ثم اضغط بالزر الأيمن على `index.html` واختر **Open with Live Server**.
3. أو افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages

المنصة منشورة من هذا المستودع (الفرع `main`، المجلد الجذر). أي ملف يُعدَّل ويُرفع هنا يظهر في الموقع خلال دقيقة تقريباً. ولنشر نسخة في مستودع آخر:


1. أنشئ مستودعاً جديداً على GitHub (مثلاً `waraq-bihibr`).
2. ارفع محتويات المجلد كما هي (يكون `index.html` في جذر المستودع).
3. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
4. بعد دقيقة يظهر رابط الموقع بالشكل: `https://اسم-المستخدم.github.io/waraq-bihibr/`
5. صورة المشاركة (`og:image`) في `index.html` مضبوطة الآن على رابط Netlify. إذا نشرت على GitHub Pages، غيّرها إلى الرابط الكامل الجديد، مثل: `https://اسم-المستخدم.github.io/waraq-bihibr/assets/og-image.png`

## الاستضافة الحالية على Netlify

المنصة منشورة على https://waraq-bihibr.netlify.app، والملف `netlify.toml` يخبر Netlify أن ينشر المجلد كما هو دون خطوة بناء. لتحديث الموقع لاحقاً، اسحب المجلد كاملاً إلى صفحة المشروع في لوحة Netlify (Deploys).

## أين أعدّل؟

كل الإعدادات في أول ملف `js/data.js`:

- **رابط الاستبيان:** ضع رابط Google Forms في `surveyUrl` ليظهر زر «شارك في الاستبيان» في المركز الإعلامي.
- **فترات التوصيل:** `delivery.windows` (الصباحية 9:00 ص – 2:00 م، والمسائية 3:00 م – 8:00 م) وأيام التوصيل `delivery.days` (الأحد إلى الخميس).
- **الرسوم:** `fees` (شراء 10 ر.س، تبادل 6 ر.س على كل طرف، مكتبة المنصة 5 ر.س، استلام التبرع مجاناً).
- **المدن والجامعات والكليات:** `cities` و`universities` و`colleges`.
- **محتوى المركز الإعلامي:** المقالات والحملة والتقويم التحريري والبودكاست والهوية والبيان الصحفي في `WB.content`.

## صفحات المنصة

| الصفحة | الرابط | ما فيها |
|---|---|---|
| الرئيسية | `#home` | البحث، ومسارات الشراء والتبادل والتبرع، وأحدث الكتب، والتوصيل، والمركز الإعلامي |
| تصفح الكتب | `#books` | بحث بالعنوان أو رمز المقرر، وتصفية بالنوع والكلية والمدينة والحالة |
| صفحة الكتاب | `#book-b1` | التفاصيل والحالة وطلب الشراء أو التبادل |
| اعرض كتابك | `#sell` | نموذج عرض الكتاب للبيع أو التبادل، مع اقتراح سعر عادل ومعاينة مباشرة |
| التبادل | `#exchange` | خطوات التبادل والمطابقات المقترحة والكتب المتاحة للتبادل |
| التبرع | `#donate` | نموذج التبرع وحجز موعد الاستلام المجاني |
| مكتبة المنصة | `#library` | الكتب المتبرع بها، تُطلب مجاناً برسوم توصيل رمزية |
| التوصيل المجدول | `#delivery` | جدول الأيام والفترات، والرسوم، وشرح تجميع الطلبات، وتتبّع الطلب |
| المركز الإعلامي | `#media` | الحملة، والمقالات، والتقويم التحريري، والبودكاست، والهوية البصرية، والبيان الصحفي، والاستبيان |
| حسابي | `#account` | كتبي، وطلباتي، وطلبات التبادل الواردة، وتبرعاتي |
| تسجيل الدخول | `#login` / `#register` | الدخول وإنشاء حساب |

## الحساب التجريبي

من صفحة تسجيل الدخول اضغط **الدخول بالحساب التجريبي**، أو استخدم:

- البريد: `demo@waraq-bihibr.test`
- كلمة المرور: `demo1234`

فيه كتابان معروضان وطلب تبادل وارد ينتظر الرد، لتجربة دورة التبادل كاملة أثناء العرض.

## ملاحظات عن النموذج الأولي

- المنصة نموذج أولي يعمل في المتصفح؛ الحسابات والكتب والطلبات تُحفظ في التخزين المحلي (localStorage) للمتصفح نفسه. عند الإطلاق الفعلي تُربط بقاعدة بيانات وخادم (مثل Firebase).
- كلمات المرور لا تُحفظ كما هي، بل تُحفظ بصمتها (Hash) بخوارزمية SHA-256، والحماية الكاملة تحتاج خادماً.
- طلبات التبادل المرسلة إلى الحسابات التجريبية يمكن قبولها بزر **محاكاة موافقة الطرف الآخر** في صفحة حسابي، لأغراض العرض.
- رابط **إعادة ضبط البيانات التجريبية** في أسفل كل صفحة يعيد المنصة إلى حالتها الأولى.
